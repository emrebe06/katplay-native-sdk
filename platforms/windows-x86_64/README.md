# Windows x86-64 runtime

Files:

- `kattplay_runtime.dll` — KatPlay C ABI runtime, WASAPI output.
- `CApi.h` — ABI 1 public header.
- `SHA256SUMS.txt` — package file checksums.

Put the DLL beside your executable or pass its absolute path to Python/Node integration. Supported playback formats: WAV, FLAC and MP3.
